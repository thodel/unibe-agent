# UniBE-Agent

Anleitung für Anfänger:innen: einen KI-Agenten ([OpenHands](https://github.com/OpenHands/OpenHands)) lokal in Docker betreiben, mit dem Sprachmodell Qwen 3.8 auf dem GPUStack der Universität Bern.

**Zur Anleitung:** https://thodel.github.io/unibe-agent/

- `index.html` – die Anleitung (GitHub Pages)
- `compose.yaml` – Docker-Compose-Datei, die die Anleitung herunterlädt
- `img/` – Screenshots
